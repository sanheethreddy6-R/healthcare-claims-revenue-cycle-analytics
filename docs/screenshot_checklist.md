# Screenshot Checklist for GitHub and LinkedIn

After you build the Power BI report, export or capture these images:

1. **Data model screenshot** - show Claims in the center with Payers, Providers, Patients, Procedures, Diagnoses, and Date around it.
2. **Revenue Cycle Overview** - full dashboard page with KPI cards and monthly/payer/A-R visuals.
3. **Denial Analysis** - full dashboard page showing denial reason and payer analysis.
4. **A/R & Reimbursement** - full dashboard page showing aging and high-dollar outstanding claims.
5. **SQL query screenshot** - one well-formatted query and result set, preferably payer performance or denial root causes.

Do not upload screenshots containing your local file paths, account name, database passwords, or any real patient data.
