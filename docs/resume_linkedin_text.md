
## Project Title

Healthcare Claims & Revenue Cycle Analytics Dashboard

## Tools

PostgreSQL | SQL | Tableau | Python | Healthcare Claims Data


- Built an end-to-end healthcare claims and revenue cycle analytics project using PostgreSQL, SQL, and Tableau across 6,000 synthetic claims.
- Developed SQL analyses for billing, collections, denial trends, payer performance, reimbursement, and A/R aging while performing data quality and referential integrity checks.
- Created an interactive Tableau dashboard tracking $1.57M in billed charges, $0.94M in collections, $133.71K outstanding A/R, an 87.57% net collection rate, and an 8.02% denial rate.

##  Project Description

Developed an independent healthcare claims and revenue cycle analytics project using PostgreSQL, SQL, Python, and Tableau.

Created and analyzed a synthetic dataset containing 6,000 healthcare claims and supporting patient, provider, payer, procedure, and diagnosis tables.

Performed SQL-based data validation and revenue cycle analysis covering billed and allowed amounts, collections, outstanding A/R, claim denials, payer performance, reimbursement trends, and payment turnaround.

Built an interactive Tableau dashboard featuring executive KPIs, monthly billing and collections trends, payer performance, denial analysis, and A/R aging with interactive payer, department, and service-month filters.

Key project results included $1.57M billed, $0.94M collected, $133.71K outstanding A/R, an 87.57% net collection rate, an 8.02% denial rate, and 27.05 average days to payment.

All healthcare data used in this project is synthetic and contains no PHI.
